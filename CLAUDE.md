## Codex (canonical docs)
- The source of truth for what Tutor **is**, **is not**, and its rules lives in `docs/`:
  - `docs/BIBLE.md` (L0) — one sentence, promise, NOT-list, architecture, **Laws**, verified state, frontier, quality bar, glossary. Stable IDs: sections `{#TUT-§N}`, laws `{#TUT-LAW-n}`.
  - `docs/USER_STORIES.md` (L2) — test-cited stories (`TUT-US-<Epic><n>`). A story is `✅` only when a real test proves it.
  - `docs/AMENDMENTS.md` (L1) — append-only; an amendment **wins** over the bible.
  - `docs/rfc/*.md` — design notes that graduate into L0/L2.
  - `docs/BIBLE.digest.md` — GENERATED by `tools/codex.ps1 digest`; never hand-edit.
- The **Laws** inherit `../MindAttic.HouseRules.md` by reference; only Tutor-specific laws (e.g. grounding-over-generation) live in the bible.
- Before editing docs, run `pwsh tools/codex.ps1 doctor` (must pass) and `pwsh tools/codex.ps1 digest` after touching `BIBLE.md`.
- A `SessionStart` hook (`.claude/hooks/inject-digest.ps1`) injects the digest as authoritative context.

## Conversation
- A bare "do" / "do it" / "yes" from the user means "continue", "keep going", "proceed". Resume the current task without asking for clarification.

## Code Style
- Do NOT use underscore-prefixed variables (e.g., `_myField`). Use `camelCase` for private fields without the underscore prefix.
- In constructors, use `this.x = x` to disambiguate field assignment from parameter.
